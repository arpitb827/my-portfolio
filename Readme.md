## 🌐 Portfolio Setup

This is a single-file HTML portfolio. No frameworks, no build step.

### Run locally
```bash
# Just open the file in your browser
open index.html

# Or use a local server
npx serve .
# or
python3 -m http.server 8000
```

### Deploy to GitHub Pages
1. Go to repo **Settings → Pages**
2. Source: `Deploy from a branch`
3. Branch: `main` · Folder: `/ (root)`
4. Save — your site is live at `https://yourusername.github.io/portfolio`

### Custom domain
1. Buy your domain (recommended: `arpitbansal.dev`)
2. Add a `CNAME` file to the repo with your domain name
3. Configure DNS at your registrar to point to GitHub Pages

### Contact Form Setup (Formspree)
The contact form uses [Formspree](https://formspree.io) to keep your email private.
1. Sign up free at formspree.io
2. Create a new form — copy your Form ID
3. In `index.html`, replace `YOUR_FORM_ID` with your actual ID:
   ```html
   action="https://formspree.io/f/YOUR_FORM_ID"
   ```
